# Language support: current status

Implemented with i18next. A language switcher (EN / தமிழ் / हिन्दी) is in the header on every page.

**Translated:** navigation labels, the Home page, and the Test page's title/subtitle/category/start-stop labels.

**Not yet translated (still English only):** Result page, History page, Device page, Batch page, and
all plain-language reasons/recommendations produced by the model. Translating those requires the model's
reason strings to be built from translation keys rather than fixed English sentences — a follow-up task,
not done here so as not to silently mistranslate anything model-generated.
